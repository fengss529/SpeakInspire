## 三条通用教训

### 1. 静默 return 是最难查的失败

没异常、没日志、界面正常，内容却不对。
Repository 层的写操作都该返回成功与否。

### 2. hiltViewModel 的 key 要区分「对象」和「会话」

按对象 id 做 key = 复用实例 = 第二次进入是旧状态。
编辑这类一次会话的场景，key 里必须带会话 id。

### 3. 测试的盲区往往在「看起来简单」的地方

状态派生逻辑复杂，值得测；
Repository 的 updateNote 三行代码，没人测——
而bug 恰恰在那里。
