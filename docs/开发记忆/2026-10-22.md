### 追加：配音与二次修订（同日）

- **加配音后总时长变 195.25s（3分15秒）**。画面时长不再手估，而是由配音实际长度决定：
  `_tts.py` 读 `_narration.json` → 逐镜合成 → ffprobe 量时长 → 写 `_timeline.json` → `_build_hf.py` 读它生成。**场景时长 = LEAD(0.45) + 音频 + TAIL(0.65)**，首镜多 0.55s、末镜多 1.6s。
- **edge-tts 装法**：清华镜像**没有**这个包（报 No matching distribution），换阿里云 `-i https://mirrors.aliyun.com/pypi/simple/` 秒装（7.3.1）。微软接口本机可直连，`zh-CN-YunyangNeural`（云扬，专业播报男声）+ `rate="+6%"`。
- **朗读前必须做文本规范化**：`——`/`—`→`，`，`–`→`到`，去掉 `『』《》` 与空格。否则破折号和 en dash 会被读成怪异停顿或直接吞掉。
- **音轨铺法**（`_mix.py`）：14 段 mp3 → ffmpeg 转 44.1k stereo s16le raw → 按各自时间码写进一个大 bytearray → 首尾 30ms 淡入淡出防爆音 → 写 wav。免 numpy。
- **最终成片走 HyperFrames 内置 audio 元素**，比 ffmpeg 后期合音更"正统"：`<audio id="vo" src="./assets/voice.m4a" data-start="0" data-duration="{TOTAL}" data-track-index="0" data-volume="1">` 放在合成根内。这样脚本本身可直接渲染出带声成片。否则 lint 会报 `audio_file_without_element`（"项目里有音频但没引用，渲染出来是哑的"）。
- ⚠️ **带圈数字 ①②③ 在 headless Chrome 里会渲染成方块**（字体回退）。chapter/标题里的序号一律改用中文「（一）（二）（三）」。
- **SVG 抽象图标的辨识度坑**：第一版「戏曲脸谱」画成圆脸+两点眼+笑弧 = 看起来像**笑脸**；「庙宇」画成窄矩形+尖顶+底部弧 = 看起来像**铃铛**。改法：脸谱用「上宽下收脸形 + 额头菱形 + 中轴竖线 + 左右柳叶形眼窝」；庙宇用「上拱飞檐 + 檐口横线 + 两端翘角 + 三立柱 + 两级台基」。**图标不配文字就容易歧义，画完必须抽帧肉眼确认。**
- 校验流程固定为：lint(0 error 0 warning) → render → 抽帧看画面 → volumedetect 看各时段有声。均值约 -30dB（含间隙）、峰值 -4.4dB 属正常。

### ⚠️⚠️ SVG 渐变会让「零宽/零高的 line」静默消失

`<linearGradient>` 默认 `gradientUnits="objectBoundingBox"`，按**元素自身包围盒**取色。
`<line>` 若是纯水平（bbox 高度=0）或纯垂直（bbox 宽度=0），包围盒退化 → 渐变无效 →
**整条线完全不渲染，且控制台无任何报错**。
