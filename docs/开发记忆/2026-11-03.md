## V0.12.0：设置页改版（卡片分组 + 删两个选项）

用户反馈：设置页几个选项分类不醒目、缺层次；「用哪个模型」意义不大；
「关掉思考模式」应默认关掉不提供选择。要求参考其他 App 做得有设计感。

### 做法

`SettingsScreen.kt` 整体重写布局（业务逻辑没动）：

- 每组一张卡片：34dp 图标方块（primary 10%）+ 组名 15sp SemiBold + 一句副标题。
  页面底色改成 `0xFFF5F3F9`，卡片纯白 + 1dp 边框（outline 10%），
  卡片间距 12dp > 卡内行距 —— **分组靠空间，不靠再画分隔线**
- 选中行：整行 `primary.copy(0.07)` 染色 + 标题变主色 / SemiBold +
  自绘 `SelectionDot`（18dp 圆，选中填色 + 白心）。
  不用 M3 `RadioButton`：它自带 48dp 触摸目标，会把行高撑起来
- 「测试连接 / 保存」从页面底部挪进服务商卡片，紧贴 API Key
- 追问/风格的编辑器、禁区只读块留在各自卡片内，前面加「进阶」分隔线
- 数据组改成 `ActionRow`（图标 + 标题 + 副标题 + 右箭头）

### 删掉的两个选项

| 选项 | 理由 |
|---|---|
| 用哪个模型 | 换服务商已带默认模型；用户没有判断依据。自定义服务商仍手填模型名 |
| 关掉思考模式 | 追问与成文**都在请求层强制关**，界面开关从来没生效过 |

`SettingsUiState.toConfig()`：预置服务商固定 `thinkingDisabled = true`，
自定义保持 `false`（对面认不认这个字段不确定，发了可能 400）。

**顺带修了一处会误导的文案**：`ErrorMapper` 的 `THINKING_ONLY` 原来写
「去设置里勾上『关掉思考模式』」——那个勾选框已经没了。
这就是删选项时必须全局搜文案的原因：**界面删了，错误提示还在指路。**

## 下午：推送到 GitHub，CI 从红到绿

### 推送

代理环境变了：`~/.gitconfig` 里有 `http.https://github.com.proxy=`（空），
**这条会盖掉 `http.proxy` 和环境变量**，所以先前的 54305 死了之后一直连不上。
当前可用端口是 Clash 的 `7890`（mixed，HTTP 与 SOCKS5 都能走）。
`5092` 之类的沙箱代理（`https_proxy=127.0.0.1:57092`）对 github 返回 **502**，必须 unset。

直连 `github.com` 时通时不通，稳定做法是 socks：

```bash
git -c "http.https://github.com.proxy=socks5://127.0.0.1:7890" push origin main
```

### CI 四个坑（依次踩）

| 现象 | 真因 | 处理 |
|---|---|---|
| 「安装 Android SDK」失败 | `android-actions/setup-android@v3` | 去掉，用 runner 自带 SDK |
| 「跑测试」1 秒失败 | `gradlew` 提交成 `100644`（Windows `core.filemode=false`），Linux 上 Permission denied | `git update-index --chmod=+x gradlew` + CI 里 chmod |
| KSP 插件「六个仓库都找不到」 | aliyun 对海外 IP 返回 **502**，Gradle 记成「坐标不存在」 | `settings.gradle.kts`：CI 上跳过镜像 |
| 想看日志 | Actions 完整日志要登录 | 失败时把 `What went wrong` 后几行抛成 `::error::` 注解，匿名可读 |

**`pluginManagement {}` 必须是 settings 脚本的第一条语句**，所以判断不能写成
文件顶部的 `val`，只能写在 `repositories {}` 里面。

现在 main = `a910443`，CI 全绿；tag `v0.12.0` 指到 `a910443`（原指 `f01e9c2`，
那个 commit 的 CI 是红的，标签页会挂个红叉，所以重新打过）。
删除并重推远端标签用过一次 `push origin :refs/tags/v0.12.0`。
